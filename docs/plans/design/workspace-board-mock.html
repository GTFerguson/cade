Streams of work: the strip, and a fuller picker

Second pass. The separate board is dropped. What is kept: the strip under the tab bar, and the same facts folded into the picker you already have, drawn the way the picker is drawn today. All data is invented. Nothing here is built except the tab bar, the pull request badges and the picker's present layout.

1  The strip

One line between the tab bar and the terminal, about the tab in front of you. It shows only what is known, so it is shorter on a tab with less going on, and absent on a tab outside any repository.
